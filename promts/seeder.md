## Описание шаблона страницы предложения для ресторанов

На данной странице будет собственная Hero секция и секция с блоком предложения.

### hero секция

Фон самой секции будет изображением @public/img/rest_h.webp с небольшим затеменением. Затеменение создай при помощи псевдо класса ::before. В контейнере секции будет заголовок h1 с текстом "Эксклюзивное предложение <br> <span>для Кафэ и ресторанов</span>" Заголовок h1 написан uppercase span внутри заголовка h1 будет меньшим шрифтом, цвет шрифта белый. Заголовок оцентрован по вертикали.

### секция с блоком предложения

Данная секция будет залита фоном цвета из переменной $categories_bg. Внутри контейнера секции размести компонент с хлебными крошками:

```php
<x-breadcrumbs.main title="Эксклюзивное предложение для Кафэ и ресторанов"></x-breadcrumbs.main>
```

Под хлебными крошками размести отдельный блок с предложеникм. Этот блок будет иметь фон белого цвета и скругленные края. внутри блока будут размещены блоки по 2 в строку. В каждой строке будут блоки с фотографией и текстом. Они должны чередоваться, текст с лева фото с права и наоборот. Блоки с фото при этом должны иметь скругленные края. Блоки с текстом не имеют заливки фоном а текст в них центрованный.

Блок с текстом будет иметь вложенный блок в котором и будет текст, этот блок отцентрован по горизонтали и вертикали. Вложенный блок будут обрамлять линии с верху и с низу которые нужно реализовать при помощи псевдоклассов ::before и ::after. Линии должны быть цвета $brand_green и толщиной в 1 пиксель, длинной 100px.
