Создай отдельный контроллер для вывода страницы контектов. Для страницы контактов создай отдельное view @resources/views/contacts.blade.php. В контроллере создай метод index() который будет возвращать этот view.

Структура страницы контактов будет следующая:

```php

@extends('layouts.all')

@section('main')
    ...

    <x-individual-section />
    <x-projects-section />

@endsection


```

Вместо "..." должна быть описанна секция в контейнере которой будут следующие элементы:

Компонент с хлебными крошками

```php
<x-breadcrumbs.main :title="$title"></x-breadcrumbs.main>
```

Заголовок h1 с текстом "Контакты"

Заголовок h1 снабди отдельным классом модификатором который добавит горизонтальную линию в один пиксель под заголовком. Стиль модификатор добавь в файл @public/scss/\_current.scss

Блок разделенный на 2 столбца. В левом столбце будет выводится контактная информация, а в правом столбце будет карта с адресом компании.

Контактные данные которые необходимо вывести на странице контактов:

- Адрес
- Телефон
- Электронная почта

Данные выводим из таблицы созданной ранее.

В правом столбце выводим карту с адресом компании. Для карты используй компонент @resources/views/components/map/map-in-page.blade.php. пример его вызова:

```php
<x-map.map-in-page name="Денталика" :geo="$contacts['geo']" :adres="$contacts['adress']" :phone="$contacts['phone']"></x-map.map-in-page>
```

Данные для карты так же выводим из таблицы созданной ранее.

Для разметки создай scss файл в папке @public/scss и подключи его в @public/scss/main.scss
