## Подготовка к верстке

Перед началом верстки изучи структуру стилей в папке public/scss и далее действуй придерживаясь этой структуры.

Перед началом верстки поредели все кнопки стилизуй их и помести в файл @public/scss/elements/\_button.scss для дальнейшего переиспользования. разные виды кнопок реализуй через классы модификаторы. для кнопок придумай hover эффект

Все иконки которые будут представлены далее в описании секций объединяй в спрайт и используй от туда.

Материалы (ассеты) которые будут представлены далее в описании секций переноси в папку public/img можешь раскладывать их внутри по папкам. При переносе оптимизируй изображения в формате png переведи их в webp.

## Принципы верстки

- При верстке не забывай про требования по доступности.
- При верстке используй все современные технологии но только те которые имеют повсеместную поддержку в разных браузерах
- Для стилизации scss, используй вложеность чтобы код стилей был компактней.
- Стили для каждой секции должны лежать в отдельном файле. Эти файлы должны лежать в директории public\scss\, начинаться с символа "\_" и подключаться в файле public\scss\main.scss
- В начале каждого файла со стилями должно быть подключение файла с переменными, реализованное следующим образом: @use 'vars' as \*;.
- Все стили которые повторно используются в различный секциях выноси в файл \_current.scss.
- Пред началом верстки заполни файл public\scss_vars.scss переменными которые ты будешь в дальнейшем использовать в подключаемых файлах. Используй переменные для - цветов, размеров шрифтов, размеров отступов. Так же можешь выносить в файл с переменными любые параметры которые сочтешь нужным.
- Каждая секция должна быть обернута в семантический тег section с осмысленным классом и Id. Внутри каждой секции должен быть контейнер описанный следующим образом :

```php
<div class="container"> </div>
```

- Всю разметку секции делай внутри контейнера описанного выше.
- Без прямой необходимости или прямых указаний описанных в этом ТЗ не стилизуй секции и вложенный контейнер, стили для них уже прописаны.
- Если по ходу выполнения работ нужно создать кнопку по умолчанию делай ее при помощи тега a с прописанным классом button.
- Созданные в ходе работы секции помещай в файл resources\views\index.blade.php перед закрывающим тегом @endsection
- Блоки внутри секций которые потенциально могут быть переиспользованы должны быть оформленны как карточки. Карточка - простой blade компонент без класса куда передаются структурированные данные и они же отображаются. В описании секций ниже я могу просить оформить внутренние блоки как карточки, выполняй эти указания. Карточки должны храниться в папке resources/views/components/cards

## Адаптация под устройства (общие требования)

- все секции должны быть адаптированы для мобильных устройств
- при написании стилей адаптации старайся их минимизировать и не преписывать лишнее
- Мобильное устройство начинается от ширины экрана 520px
- Планшеты начинается от ширины экрана 820px
- Прими во внимание что для слайдеров у которых количество отображаемых элементов на десктоп версии > 1 нужно прописать брекпоинты при инициализации.
- Ниже в разделе с описанием секций могут быть описаны требования для ее мобильной адаптации, учитывай эти требования.
